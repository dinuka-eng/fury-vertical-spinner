# Mechanical files

Add CAD and drawings here as they are produced:

- `fury_weapon_assembly.*` — full robot + weapon assembly (STEP export plus native file)
- `blade_profile.*` — single-tooth blade profile (DXF for cutting)
- `uprights.*`, `feeder_forks.*` — dimensioned drawings
- `mass_cog_report.*` — mass and centre-of-gravity report from CAD

Design rules and the checks to run before cutting metal are in [`../docs/MECHANICAL.md`](../docs/MECHANICAL.md).
